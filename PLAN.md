# Simple Linear Regression Calculator — Project Plan

A Weka/Orange-style simple linear regression calculator built with **Julia only**, with **HTML and CSS used strictly as the UI** (no JavaScript).

---

## 1. Goals and Decisions

| Item | Decision |
|---|---|
| Language | Julia for all logic, server, parsing, HTML generation, and chart generation |
| UI | HTML + CSS only. **No JavaScript at all** |
| Packages | Allowed: HTTP.jl (server, uploads), CSV.jl, XLSX.jl. Regression math is **handwritten** (no GLM.jl / Statistics shortcuts for the core formulas) |
| Accuracy | Results must match Excel / Google Sheets |
| Hosting | Localhost only; source will be uploaded to GitHub |
| Reference | The handwritten table is a **guide** (the exact table could not be found online) |
| Look and feel | Similar to Weka / Orange; creative UI. A separate **design md** will be provided later |

---

## 2. Reference Table and Formulas

The calculation table follows the handwritten sheet:

| X | Y | x − x̄ | y − ȳ | (x − x̄)(y − ȳ) | (x − x̄)² | Predicted Y |
|---|---|---|---|---|---|---|

Formulas:

```
x̄ = Σx / n          ȳ = Σy / n

b = Σ(x − x̄)(y − ȳ) / Σ(x − x̄)²        (slope)
a = ȳ − b·x̄                              (intercept)

ŷ = a + b·x                              (predicted Y)
```

### Verification dataset (use as the first test)

X = 1, 2, 3, 4, 5  and  Y = 2, 4, 5, 4, 6

| Value | Expected |
|---|---|
| x̄ / ȳ | 3 / 4.2 |
| Σ(x−x̄)(y−ȳ) | 8 |
| Σ(x−x̄)² | 10 |
| b | 0.8 |
| a | 1.8 |
| Predicted Y | 2.6, 3.4, 4.2, 5.0, 5.8 |
| r | 0.8528 |
| R² | 0.7273 |
| Std. error (STEYX) | 0.8944 |
| MAE / RMSE | 0.64 / 0.6928 |

## 3. Architecture

Because there is no JavaScript, the app is **server-rendered and stateless**: every action is an HTML form post, Julia returns a full HTML page, and the data travels back in the form fields on each request. Charts are SVG generated by Julia. Tabs are pure CSS (radio inputs + `:checked`).

```
slr-calculator/
├── Project.toml
├── README.md
├── PLAN.md
├── src/
│   ├── main.jl          # server start + routes
│   ├── regression.jl    # handwritten formulas (DONE)
│   ├── importer.jl      # CSV / XLSX → vectors
│   ├── render.jl        # HTML builders: grid, table, formulas, SVG chart, results
│   └── export.jl        # download results as CSV
├── static/
│   └── style.css        # built from the design md
└── test/
    └── excel_match.jl   # compares against hand-computed / Excel values (DONE)
```

### Routes

| Route | Purpose |
|---|---|
| `GET /` | Main page with an empty or sample grid |
| `POST /calculate` | Read the grid, run regression, render results |
| `POST /rows` | Add or remove rows (re-renders the grid) |
| `POST /upload` | Multipart upload of `.csv` / `.xlsx`, then show column pickers |
| `POST /select` | Apply the chosen sheet and X / Y columns to the grid |
| `POST /predict` | Predict Ŷ for a new X |
| `GET /static/style.css` | Serve the stylesheet |
| `POST /export` | Download the calculation table and results as CSV |

## 4. Input

### 4.1 Manual entry (Excel-like)
- An HTML form grid with one X input and one Y input per row.
- "Add row" and "Remove row" are submit buttons that re-render the page.
- Blank rows are ignored; non-numeric cells produce a clear inline error naming the row.

### 4.2 File import (Weka-like)
- File upload for `.csv` and `.xlsx`.
- For Excel files, a sheet dropdown; for all files, **X column** and **Y column** dropdowns (like Weka's attribute selection).
- The first row is treated as the header (with a checkbox to change this).
- Imported data fills the grid so it can still be edited before calculating.

## 5. Process (`regression.jl`) — implemented

`slr(xs, ys)` returns a struct with every intermediate value so the UI can show each step:

- n, x̄, ȳ
- columns: x − x̄, y − ȳ, (x − x̄)(y − ȳ), (x − x̄)²
- Σ(x−x̄)(y−ȳ), Σ(x−x̄)²
- b, a, predicted Y, residuals
- SSE, SST, r, R², standard error (n − 2), MAE, RMSE

### Excel equivalents

| Result | Excel / Sheets |
|---|---|
| b | `=SLOPE(Y, X)` |
| a | `=INTERCEPT(Y, X)` |
| r | `=CORREL(Y, X)` |
| R² | `=RSQ(Y, X)` |
| Std. error | `=STEYX(Y, X)` |
| Predicted Y | `=FORECAST.LINEAR(x, Y, X)` |

### Edge cases

| Case | Behavior |
|---|---|
| Fewer than 2 points | Error message |
| X and Y length mismatch | Error message |
| All X identical (Σ(x−x̄)² = 0) | Error: slope undefined |
| All Y identical | r and R² shown as N/A (Excel gives `#DIV/0!`) |
| Exactly 2 points | Std. error shown as N/A (needs n > 2) |

Display rounding is a UI setting (decimal places); calculations always use full `Float64` precision.

## 6. Output (single results page)

Shown in this order:

1. **Calculation table** — X, Y, x − x̄, y − ȳ, (x − x̄)(y − ȳ), (x − x̄)², Predicted Y, with a Σ totals row and x̄ / ȳ shown.
2. **Slope (b) formula with substituted values**
   `b = Σ(x−x̄)(y−ȳ) / Σ(x−x̄)² = 8 / 10 = 0.8`
3. **Intercept (a) formula with substituted values**
   `a = ȳ − b·x̄ = 4.2 − (0.8)(3) = 1.8`
4. **Equation** — `ŷ = 1.8 + 0.8x`
5. **Graph** — SVG scatter plot of the data points with the regression line, labeled axis ticks (like the sketch), optional residual lines. Axes scale from the data's min and max.
6. **Weka-style summary panel** — equation, r, R², std. error, MAE, RMSE, number of instances.
7. **Predict box** — enter a new X to get Ŷ.
8. **Export** — download the table and results as CSV.

The formula lines and the SVG are built from the **actual computed values**, so the display can never disagree with the table.

## 9. Testing and Validation

- **Unit tests** (`test/excel_match.jl`): sample dataset values, plus edge-case errors.
- **Excel cross-check**: paste the same data into Excel / Sheets and compare against the functions in section 5. Tolerance: relative difference below 1e-9.
- **Extra datasets**: add 2 or 3 more (different n, negative slope, decimals) with Excel-verified values.
- **Import tests**: same dataset as `.csv` and `.xlsx` must give identical results to manual entry.
- **Manual UI checks**: add and remove rows, blank rows, bad input, large files (a few thousand rows).
